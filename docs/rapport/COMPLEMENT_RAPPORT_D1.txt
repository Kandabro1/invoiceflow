1. Colonnes P02 absentes ou renommées
Aucune. Toutes les colonnes P02 sont présentes (les noms anglais TypeScript sont mappés en snake_case français via @Column({ name: ... })).

2. Index et clés étrangères ajoutés (hors P02)
- uq_facture_numero : UNIQUE (utilisateur_id, numero) sur facture pour garantir l'absence de doublons de numéros (RG3).
- idx_proforma_reference : UNIQUE (utilisateur_id, reference) sur proforma pour la génération aléatoire.
- Index ajoutés : utilisateur_id sur client, proforma, facture, paiement, refresh_token ; (utilisateur_id, statut) et (utilisateur_id, date_echeance) sur facture (performance Dashboard) ; token_hash sur refresh_token.
- FK : ON DELETE RESTRICT partout (sauf CASCADE sur les lignes enfants de documents et refresh_token).

3. Contraintes d'unicité
- email sur utilisateur est UNIQUE.
- code sur taux_tva est UNIQUE.
- numero sur facture est UNIQUE par utilisateur (NULL autorisé tant que BROUILLON).
- reference sur proforma est UNIQUE par utilisateur.
- token_hash sur refresh_token est UNIQUE.
