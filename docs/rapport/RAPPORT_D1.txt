(4) Hypothèses faites
- Les DECIMAL sont typés string en TypeScript, pas de decimalNumbers: true.

(5) Compatibilité MariaDB/MySQL (Point 9 du chef de projet)
- JSON : MariaDB stocke en LONGTEXT + CHECK, MySQL a un type natif. L'API lisant l'objet entier, c'est transparent. À tester sur MySQL hébergé.
- Dates : Types datetime et date identiques. Surveiller le fuseau horaire (timezone) sur le serveur de production.
- Décimaux / Verrous : DECIMAL(15,2) identique. Le verrou pessimiste (pessimistic_write sur InnoDB) fonctionne pareil, à tester sous forte concurrence sur MySQL hébergé.
